## Prerequisites

- **Python** 3.8+ (3.12 recommended with Docker)
- **CMake** 3.16+
- **GCC/G++** 9.4+
- **Git** with submodule support

For workload generation with AIOB (computation profiling), a **NVIDIA Hopper (SM90)** or **Blackwell (SM100)** GPU is required.
